## Reflection

**Ensuring functionality and security:**  
I ensure my code is functional by writing unit tests for each method and integration tests to verify interactions between components. Security is maintained by validating input, following secure coding practices, and reviewing dependencies to prevent vulnerabilities. Testing and best practices together help produce reliable and secure software.  

**Interpreting user needs:**  
I analyze requirements to understand what the user expects the program to do. By breaking these needs into specific features and incorporating feedback, I design software that solves real problems efficiently and intuitively.  

**Approach to designing software:**  
I take an iterative and structured approach. I begin with planning the classes, methods, and their interactions, keeping maintainability, readability, and scalability in mind. I integrate testing early to validate components and adjust the design as needed, ensuring the software is robust and adaptable for future updates.
